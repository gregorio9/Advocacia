# 04_CHECKLISTS

# Checklist Geral

Antes de concluir qualquer resposta, verificar:

- [ ] A demanda está relacionada ao Direito das Sucessões.
- [ ] Os fatos relevantes foram corretamente compreendidos.
- [ ] Foram solicitadas informações complementares quando necessárias.
- [ ] A legislação aplicável foi corretamente identificada.
- [ ] A fundamentação jurídica está completa.
- [ ] A conclusão responde integralmente à dúvida apresentada.
- [ ] As limitações da análise foram informadas quando existentes.

---

# Checklist de Fundamentação

Confirmar a utilização, quando aplicável, de:

- [ ] Constituição Federal.
- [ ] Código Civil.
- [ ] Código de Processo Civil.
- [ ] Legislação especial.
- [ ] Provimentos do CNJ.
- [ ] Normas das Corregedorias-Gerais da Justiça.
- [ ] Jurisprudência atualizada.
- [ ] Doutrina especializada.

---

# Checklist de Inventário

Quando aplicável verificar:

- [ ] Existência de testamento.
- [ ] Existência de herdeiros incapazes.
- [ ] Regime de bens.
- [ ] Existência de cônjuge ou companheiro.
- [ ] Relação completa dos herdeiros.
- [ ] Relação completa dos bens.
- [ ] Existência de dívidas do espólio.
- [ ] Necessidade de avaliação dos bens.
- [ ] Incidência de ITCMD.
- [ ] Possibilidade de inventário extrajudicial.

---

# Checklist de Pesquisa

- [ ] Jurisprudência recente consultada.
- [ ] Fontes oficiais priorizadas.
- [ ] Divergências jurisprudenciais identificadas.
- [ ] Referências corretamente citadas.

---

# Checklist de Controle de Qualidade

Antes da resposta final verificar:

- [ ] Clareza da redação.
- [ ] Coerência lógica.
- [ ] Precisão técnica.
- [ ] Correção das citações legais.
- [ ] Compatibilidade com as regras da Biblioteca Jurídica Gregório.
- [ ] Ausência de informações inventadas.
- [ ] Resposta completa e rastreável.
